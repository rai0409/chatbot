## Scope

Implement only the following:

1. Sample document set + conversion run:

- Create small synthetic sample documents under eval/cases/sample_docs/ (CSV, XLSX, DOCX, PPTX — generated by a committed helper script using the same stdlib zip/xml writers as the tests; no binary blobs of real customer data; PDF sample generated via fitz if available, else skipped with reason).
- Convert all samples with the Prompt018 CLI into eval/cases/multiformat_chunks.jsonl (merged, per-file source_doc preserved).

2. Multi-format eval corpus:

- eval/cases/multiformat_cases.jsonl with at least 12 labeled cases: per format at least one retrieval-positive case (gold_chunk_ids), at least one XLSX/CSV qa_pair answer-only-term case, one DOCX heading/section case, one PPTX slide case, and at least 2 abstain-labeled cases.
- Verify with eval.runner in deterministic mode; record runs/eval/prompt019_multiformat_check.json. Calibrate strict expectations to current verified behavior (smoke-corpus convention); gold-only labels are measurements.

3. Import manifest + duplicate detection:

- scripts/import_manifest.py (or repo-consistent location): given one or more canonical JSONL files, produce a manifest JSON (per source_doc: chunk count, chunk ids hash, tenant_id set, source_type, duplicate ids within/across files, collision with an existing manifest if provided).
- Duplicate detection must flag: repeated chunk ids, identical text under different ids (exact-hash level only), and tenant_id mismatches within one source_doc.

4. One-command dry-run import:

- scripts/onboard_documents_dry_run.sh (or .py): input = directory of documents + tenant id; runs convert → manifest → validation → prints what WOULD be ingested (collection name, counts) without writing to any vectorstore. An explicit --execute flag may perform ingest but ONLY into a non-production collection name that must be passed explicitly; default is dry-run.

5. Targeted tests only:

- manifest: counts, duplicate-id detection, cross-file collision, tenant mismatch
- dry-run script: produces expected plan output and does not touch vectorstore (assert no chroma writes — e.g. fake/monkeypatched ingest entry)
- multiformat eval cases load via eval.runner load_cases
- sample-doc generator is deterministic
