# 質問のサジェスト

承認済み QA の質問を、入力に合わせて候補として返す。`GET /chat/suggest?q=…&tenant_id=…&limit=5`（1〜10）。

- **候補の出どころは、呼び出し側のテナントの承認済み QA の質問だけ**（承認済みの別表現 `approved_aliases` も照合に使う）。
  回答は返さない。他のテナントや他の利用者の質問は含まれない。承認済み QA が無効なら `{"suggestions": []}`。
- 照合は承認済み QA の完全一致検索と同じ強い正規化（NFKC・大文字小文字・句読点・空白を無視）。入力が 2 文字未満なら返さない。
  先頭が一致するものを先に、含むだけのものを後に、同順位はファイルの並び順。別表現で一致した場合も、
  **正式な質問文**を返す（`via: "alias"`）。1 つの質問は 1 回だけ。
- 応答: `{"suggestions": [{"text": 正式な質問, "qa_id": …, "match": "prefix" | "contains", "via": "question" | "alias"}]}`。
- `/chat/source` と同じ API 認証・テナント認可・レート制限。入力中の文字列はログにも監査にも残さない。
- チャット画面はまだこのエンドポイントを呼ばない（入力欄が複数行のため、候補の表示は別の UI 変更として行う）。

候補の質問を選ぶと、承認済みの回答に直接届く（`/chat` の承認済み QA の経路）ため、「よくある質問に早く着く」効果がある。
候補は承認済み QA を増やした分だけ増える（質問の言い換えの追加は 3-5）。
