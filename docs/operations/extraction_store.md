# 抽出結果の保存（OCR の行・信頼度・座標）

OCR は、行ごとに文字・信頼度（0〜100）・位置（描画したページ画像のピクセル座標）を返す。これまで変換器が使っていたのは
ページのテキストと平均の信頼度だけだった。6-1 は、**スキャンで OCR したページの行データを保存**し、6-2 以降のレビュー
（低信頼の行を見つけて直す）の材料にする。

## 保存するもの

`EXTRACTION_STORE_DIR`（既定 `data/extraction/`、`.gitignore` 済み）の `<テナント>/<キー>.json`。キーは（テナント, 文書名）のハッシュ。

| 項目 | 内容 |
|---|---|
| `tenant_id`, `source_doc`, `file_sha256`, `saved_at` | 文書の識別と、保存時のファイルの SHA-256 |
| `file_path` | 元ファイルの場所。**`INGEST_ALLOWED_ROOTS` の中にあるときだけ**（ページのプレビュー用。クライアントには返さない） |
| `pages[]` | `page`, `dpi`, `width_px`, `height_px`, `engine`, `confidence`, `needs_review`, `lines[]` |
| `lines[]` | `id`（`p3-l12`）, `text`, `confidence`, `bbox`（`[x0, y0, x1, y1]`、ページ画像のピクセル） |

- `needs_review`: ページまたはいずれかの行が `EXTRACTION_REVIEW_MAX_CONFIDENCE`（既定 80）未満、または信頼度が無い。
- チャンクは変えない（行データはチャンクに入れない。大きく、チャンクは行をまたいで切られるため）。
- 文書を取り込むたびに**作り直す**ので、常に最新の抽出を表す。レビューの決定（6-2）は別に保存され、作り直しの影響を受けない。
- 保存の失敗は取り込みを失敗させない。`EXTRACTION_STORE_ENABLED=false` で保存を止められる。

## 対象外

- テキスト層のあるページ（OCR していない）には行データも記録も無い。
- ページ内の画像だけを OCR した結果（ページ全体の OCR ではないもの）は保存しない。
- 実際の OCR エンジン（Tesseract / PaddleOCR）での検証は未実施。テストは偽の OCR 結果で、座標と信頼度の受け渡しを確かめている。
