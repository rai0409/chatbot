# LLM モデルの選定（決定と、その条件）

決定日: 2026-10-29。回答生成に使うのは、一般的な PC で RAG の回答に使われる大きさの小型〜中型のモデルです（高性能な大型モデルは使わない）。
モデルは設定のプロファイル（`docs/operations/llm_gateway.md`）で差し替えられます。**ここでの決定は、評価ゲートを通ることを条件とした「採用方針」です。**
自社の質問票での測定が終わるまでは、「最良」と断定しません。

## 決定

| 役割 | 決定 | 理由 |
|---|---|---|
| ローカル（既定） | **Qwen3 系の 8B 級（量子化）**、GPU が 16GB 以上ある環境では 14B 級。Ollama / vLLM の OpenAI 互換 API で提供する | 日本語の評価（Nejumi 系の分析）でオープンモデルの上位に一貫して入る。Apache-2.0 で、商用・将来の SaaS にも使える。8B の量子化版は一般的な PC の GPU（8GB 前後）で動く |
| クラウド（廉価） | **OpenAI の最新の小型・低価格クラスのモデル**（名称は着手時に公式の一覧で確認して設定する）。API は OpenAI 本来の Chat Completions | このシステムの呼び出しは OpenAI 互換 API。本来の API なので、互換層の制限がない。後述の理由で Claude を主にはしない |
| 候補（同じ質問票で比較） | Qwen3 Swallow（日本語の追加学習。Apache-2.0 とされる）、Gemma 4 系（ライセンスの条件を確認）、Nemotron Nano 9B JP（ライセンスを確認）、Claude Haiku 5.5（`claude-haiku-5-5`、ネイティブ API の対応後）、Gemini の Flash 級 | 日本語の RAG での優劣は、独立した比較が見つからないため、自社データでの測定で決める |
| 採点（judge） | 回答生成とは別系統のモデル（クラウド） | 同じモデルで自己採点すると甘くなる偏りが出る |

## Claude を主にしない理由（現時点）

Anthropic の公式文書は、OpenAI SDK の互換層を「主にテストと比較のためのもので、多くの用途で本番向けとは見なさない」と述べています
（[OpenAI SDK compatibility](https://platform.claude.com/docs/en/api/openai-sdk)）。プロンプトキャッシュが使えず、未対応の項目が黙って無視されます。
このシステムは OpenAI 互換 API で呼ぶため、Claude を使うなら**ネイティブ API のアダプターを足す**のが本来の形です（未実装。下の「次の作業」）。
アダプターができれば、Claude Haiku 5.5 を候補として同じ質問票で比較します。

## 決定の条件（満たさなければ次点に差し替える）

1. 同じ質問票・同じ根拠で、**LLM なし（抽出型）と比べて**、正答率が下がらず、誤受理率が基準（1% 未満）を超えないこと。
2. 文単位の根拠検証と値の照合を通った回答だけを使うこと（通らなければ抽出型の回答に戻す）。
3. 応答時間の目標（検索のみ p95 2 秒、LLM あり p95 8 秒。実測で調整）を満たすこと。
4. ライセンスが、社内利用と将来の SaaS の両方で使える条件であること。
5. クラウドのモデルは、契約で「入力を学習に使わない」「ログの保持期間」「処理されるリージョン」を確認できること。

## 調査の出典と限界

- [Nejumi 系の日本語 LLM ランキングの分析（Qualiteg, 9 月版）](https://journal.qualiteg.com/llm-ranking-2026/): オープンモデルの首位が Qwen 系。
- [VRAM 別の日本語向けローカル LLM の推奨](https://note.com/daikidomon/n/nbcc8e1917d64?hl=en): 小さい GPU では Qwen3 系と Qwen3 Swallow。
- [2026 年夏のローカル LLM の整理（Classmethod）](https://dev.classmethod.jp/en/articles/local-llm-guide-2026-summer/)、[日本語 LLM の比較（Lilting）](https://lilting.ch/en/articles/japanese-llm-options-compared)。
- 限界: 資料の多くはベンダー・実務者の記事で、**日本語 RAG の同条件の比較ではありません**。モデルの版の名称（Qwen3.5 / 3.6 など）は資料の間で食い違い、確認できないものがあります。
  そのため、版は「Qwen3 系の 8B 級・14B 級」までを決定とし、具体的なモデルは評価で決めます。
